兴趣

此处存放自己感兴趣的一些领域的内容，包括自己整理、思考的，别处摘录的，读书笔记、评论等等。希望给自己的人生找点乐子，多志于鸟兽虫鱼，此为个人兴趣与话题收集地。

下列自己感兴趣的领域/话题：中医（个人称之为传统医学，被人誉为中国文化活化石，包罗万象，所以应该会有不少子话题）、古籍（繁体竖排，文字之美，千年传承，文化之富）、太极拳（因为体弱的原因，学习练习过一段时间，自认为有所助益，这与中医有交集）、编程（前端为主，之前自学过 HTML 和 CSS，也折腾博客建站，曾经也希望能在技术上有所进步）、写作（这方面，并不特别明确是兴趣还是一点想像，希望以后能靠码字获得一种新的生活）、生态农业（有机种植、自然种植之类，因为是农民的后代，对农业有部分了解，前些年对生态种植更是有些冲动想去实践，另外对村居生活仍然很向往）。

另外，一个爱好是收书，对，不是看书，仅仅是收集各种书，买书如山倒的那种。有时间整理整理家中的藏书。

1. 中医#

学院派将中医分解为：基础理论、诊断学、方剂学、内科学、中药学等等，传统医学没有如此之分，医学是一个整体，研究的是天地人身，但也有不少学派，如伤寒、温病之类，窃以为只是对待疾病的认识角度不同而已。目前最感兴趣的是本草，有想法将村里（江南地区）的野生草药作一个记录和整理；另一个想要努力学习加深认识的是内经，只是心有余而力不足；此外还有伤寒，希望加深自己面对日常疾病的处理能力。中医首重治未病，所以了解学习传统医学的主要目的，也是为养生，谁让自己体弱多病呢。

1.1. 内经#

《内经》是一部人体使用手册，一门从天文学、天地人角度研究人体的学问。是传统医学的真正鼻祖。

2. 古籍#

目前正在学习中华书局古籍整理基础班（线上），计划今后慢慢将业余时间花在古籍整理之上，为中华文化传承尽一份绵力。

几年前录入初校过一部《医家千字文》，可算是首次接触这一事业。

3. 太极拳#

太极拳，仅以名称言，便极有深意。拳学流派也有多种，陈式、杨式、武式、孙式、叶传、郝传之类。我学习过的有陈式（108式小架，但没学完）、武式（郝传96式，邓传无手），目前以练习邓传武式63式为主。个人学拳只为养生，完全没有网络上流行的技击比武之心，因为经实践确有养生之效，但因从未学习过拳学的打法，根本不知怎么用，体弱也不敢用。

4. 编程#

曾在一位先生关于将来“三教九流”的论述中，将技术人才列为上九流，所以对编程兴趣更增，当然这是后话。先前，只是接触了自由软件和开源运动，对他们的理念较为认同，又学习使用过 GNU/Linux 系统，稍微了解些技术的历史；另外又觉得搭个网站写博客很有趣，所以慢慢接触了些前端的知识，虽然进步很慢，时常停滞。这一块，总归还是以先前接触过的 Linux 和前端知识收集整理为主吧。

5. 写作#

初中和高中都得为写作比赛的奖项，但当时从来没想过以后会将写作作为兴趣，因为上语文课最讨厌的是写作文。也是有些奇葩的结局吧。可能受网络小说影响，或者 XHS 上那些个读书博主的影响吧。

6. 农耕#

或曰生态农业，以有机、自然种植为主，为健康生活为目标。受鱼兄影响而关注的一个领域。近些年返乡从农的想法越来越浓，但从未真正跨出那一步。人是越来越老了，不知道今后还有没有契机。或许接下来也就是个键盘农人。

目前在正实践“周末农夫”的生活，以期早日真正走上半耕半读的理想人生。
