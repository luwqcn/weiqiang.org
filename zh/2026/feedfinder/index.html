用 WorkBuddy 造了个 RSS 线上阅读器 feedfinder

2026-11-22收录于「技术」约 1101 字

平时空闲了，喜欢浏览一些独立博客，特别是生活类的，能看到不同的人生经历，能开阔眼界，也可算是对平淡生活的一点有益调剂。

找过一些 RSS 阅读器的 APP，要么是不跨平台，要么是用着不习惯，也就不了了之。

后来准备把常看的博客放在收藏1里，如果看到不错的博客，慢慢增加这个列表，站点只要能打开，浏览起来也方便。但有个问题，这样并不知道哪个网站更新了。

也可以从博客聚集站看，其实这是当前常用的看博客的方式了。方便是方便，但因为聚集站点博客过多，有些并非自己想看的，信息过于驳杂了，且通常缺少筛选功能。

所以想着，能不能自己参考这样的站点，做一个线上的 RSS 订阅阅读功能，RSS 源靠自己手工维护，只列自己感兴趣的博客，这样自己每天只要打开一个网页，就可以看到关注的博客最新更新的文章，如果想留言评论，点开对方博客就可以了，相当方便。

于是把功能需求告诉了 WorkBuddy, 只花了很短的时间，一个基本满足当前我自己博客阅读需要的轮子造好了，我把这个命名为 feedfinder, 命名学的 BlogFinder, 主要是自己常浏览。

1. 功能与实现#

主要功能就是一个静态的 RSS 聚合阅读站，通过一个 orgmode 源文件，定期抓取 RSS 源更新，展示近两天内的博客文章。为什么选了两天内更新的文章，因为当前列表源数量不多，且应该也不会太多，如果一天的话，可能会一篇文章都没有。所以为了有文章看，还加了三个聚合站的订阅源。

1.1. 订阅源#

源文件是用 orgmode 文件来维护的，命名为 ff.org, 在本站中作为一个独立页面存在，可以浏览这里2，格式比较简单，一个标题一个博客，标题下用 :properties: 添加订阅源，是否订阅，更新时间等信息，比如： 

** [[https://weiqiang.org][危墙]]
:PROPERTIES:
:URL: https://weiqiang.org/index.xml
:ENABLED: yes
:INTERVAL: 14400
:END:

也可以在标题后面加 :tag: 标签，会作为一个分类展示，目前只对一些同龄的博客加了 80后 的标签。

1.2. 实现方式#

技术栈：Python（feedparser + httpx）+ SQLite 存状态 + 静态 HTML/JS/CSS，GitHub Actions 定时跑，wrangler 直传 Cloudflare Pages。无后端、无数据库服务。

这一段是 WorkBuddy 描述的，对于技术我并不懂，这个过程中我所做的操作就是建一个 Github 仓库，建一个 Cloudflare Pages 项目，然后把 Pages 项目的 API 设置到了 Github 仓库的 Actions Secret 里。

每次我更新 ff.org 文件，推送到 Github 仓库后，Actions 会自动构建一次，如果有新文章，会将构建产物上传到 Pages，站点就能实时看到更新。还有个机制是，定期（目前设了 4 小时）读取 RSS 源，如果有新文章，也会构建上传一次。

当然，要感谢像 Cloudflare, Github 这样的提供免费基础设施的公司，让折腾有了用武之地。
