纯文本生活

2026-11-03约 1121 字

大概十多年前，折腾博客的时候接触到了静态博客生成器（SSG），随之而来的是认识了 markdown, 既而又了解到了 orgmode, 当读到 Orgmode 主页那句 Your life in plain text （你的纯文本生活）时，被深深吸引，然后浅浅尝试。

如今整理，发现还是那个时候留下的 org/md 文件，还是一如既往地留在了硬盘的角落里，没有随时间而混乱与不可寻找。前段时间，翻到了大学时代用 word 记录的文件，发现设了密码，打不开了，遗憾。此时才明白，纯文本对于数据的意义。

1. 什么是纯文本#

纯文本（Plain Text）是一种只包含文字内容本身、不携带任何格式信息（如字体、颜色、大小、加粗、斜体等）的最基础的文本文件格式，常见以 .txt 格式结尾，你可以用任何一款文本编辑器打开、阅读、编辑。

纯文本的优势有：

  1. 可迁移，一台正常的电子设备都可以打开、阅读和编辑，能经受住时间的考验；
  2. 非商业，使用纯文本，可以让你远离商业公司、商业平台的限制，不被任何商业软件绑定；
  3. 能独立，这与远离商业软件相关，你不必陷入因为没有了某款软件而无法使用文本的尴尬；
  4. 离线友好，你不用依赖那些需要网络的工具，在离线状态依然能很好地使用；
  5. 易于转换，纯文本能方便地转换格式，比如从 markdown 转成 orgmode。

劣势就是在习惯图形环境的今天，纯文本是一种非所见即所得的方式，不那么直观可见。

2. 核心理念#

纯文本生活基于以下几个理念：

  1. 数字极简。只保留真正需要的工具，减少其他的格式干扰；让文字回归内容本身，而不是排版、主题等效果。
  2. 可靠可读。因为纯文本文件的特点，任何文本编辑工具都可以阅读编辑，且体积小，几乎能永久保存。
  3. 数据自主。不必被商业软件绑架，造成迁移的难度。
  4. 持久积累。专注于内容，把记忆、想法、笔记等从大脑转移到文本中，长久积累自己的数据资产。

3. 实践形式#

markdown + Jekyll 是我最初尝试过的实践方式，这是 Github 官方 Pages 的技术方案，用于搭建个人博客，每篇博客文章写一个 markdown 文件，交给 jekyll 生成网页，自己只用关注内容，其他的交由 Jekyll 解决。后来使用了 Emacs + Orgmode, 用 orgmode 写文章，内置的 ox-html 直接导出 html。

以上两种算是我自己的实践。但其实只能算是一种，只是一个博客运用。

而真正的纯文本生活包含的更多，比如记日记写笔记，一个 .txt 或 markdown 文件写一年或一个主题；写作，先纯文本写完，再用 LaTex 等排版工具排版；日程管理，比如 todo.txt, 或者 Orgmode。

纯文本生活追求的是 简单、持久、可迁移、可专注, 用朴素的方式保存最重要的内容。在这个时代，数字资产也是个人最可宝贵的一种资产，值得我们用心去守护。

我的想法是把站点慢慢改造成自己的数字后花园，除了曾经的往事琐碎记录外，知识性的内容可以有持续更新的能力，同时能以此为锚点，链接线上线下，提升自己的学习、工作效率。

基于此目的，纯文本是我选择的一个代价最低，易于操作，且能够实践的方案。
